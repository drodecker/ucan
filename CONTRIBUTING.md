# Contributing to UCAN

UCAN is an early-stage protocol proposal. The most valuable contributions are currently careful criticism, threat analysis, competing designs, and concrete examples.

## Ways to contribute

- Open an issue describing a design flaw or ambiguity
- Propose alternative authorization or trust models
- Add threat scenarios
- Improve terminology
- Provide DNS, registry, resolver, or standards-process expertise
- Build a small experimental implementation
- Submit interoperability test cases

## Pull requests

Please keep pull requests focused.

For material protocol changes, include:

- the problem being addressed;
- the proposed change;
- alternatives considered;
- security implications;
- interoperability implications;
- unresolved questions.

## Discussion standards

Critique ideas, not contributors.

Claims about DNS, ICANN, IANA, registries, cryptography, blockchains, or standards processes should include references where practical.

## Specification changes

The specification is versioned.

Breaking changes should update the draft version or clearly note incompatibility.
